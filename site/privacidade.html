Política de privacidade

Última atualização: 26 de outubro de 2026

1. Quem somos

O HUROH é uma aplicação pessoal de finanças, agenda e tarefas. Para qualquer questão sobre os teus dados, escreve para huroh@outlook.pt.

2. Que dados recolhemos

  • Conta: as contas são criadas só com o Google. Recebemos do Google apenas o nome, o email e a foto de perfil da tua conta (podes mudar o nome e a foto na aplicação). O HUROH não guarda palavras-passe e não tem acesso à tua palavra-passe do Google, ao Gmail, aos contactos nem a mais nenhum dado.
  • O que registas: movimentos, categorias, eventos, tarefas e preferências da aplicação.

3. Para que usamos os dados

Só para a aplicação funcionar: criar e identificar a tua conta, mostrar o teu perfil e guardar e sincronizar a informação entre os teus dispositivos. Não usamos os dados para publicidade, não os vendemos e não criamos perfis de utilizador.

4. Onde ficam guardados

  • No serviço Supabase, em servidores na União Europeia (Irlanda), com acesso restrito: cada conta só consegue ver os seus próprios dados.
  • No teu dispositivo, para a aplicação funcionar sem internet. Na aplicação de computador é também feito um backup diário na pasta Documentos do teu PC, que só tu controlas.

5. Com quem partilhamos

Com ninguém, exceto os serviços técnicos necessários para a aplicação funcionar: o Supabase (alojamento dos dados e das contas) e o Google (para entrares na tua conta).

6. Uso dos dados do Google

O uso e a transferência de informação recebida das APIs do Google pelo HUROH cumprem a Política de Dados do Utilizador dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

7. Durante quanto tempo

Enquanto a tua conta existir. Quando terminas sessão num dispositivo, os dados locais desse dispositivo são apagados. Em Definições → Apagar conta, a conta e todos os dados são apagados de imediato; não guardamos cópias (cópias técnicas do alojamento são eliminadas automaticamente em até 30 dias).

8. Os teus direitos

Podes exportar os teus dados (Definições → Exportar dados) e apagar a conta (Definições → Apagar conta) a qualquer momento, dentro da aplicação. Para acesso, correção ou outros pedidos escreve para huroh@outlook.pt; respondemos no prazo de 30 dias. Tens também o direito de apresentar reclamação à Comissão Nacional de Proteção de Dados (CNPD) ou, no Brasil, à ANPD.

9. Alterações

Se esta política mudar, a data acima é atualizada e, se a mudança for importante, avisamos na aplicação.
